# the structure of ecospold
- used for ecoinvent v3
- created based on hearing may 2009
- designed to represent all three stages of LCA: UPR (unit process raw), LCI and LCIA
- features:
  - Properties of exchanges:
    - dry mass,
    - wet mass,
    - carbon content
  - Mathematical relations in a new formula language and variable names for exchanges, properties, and parameters
  - Use of UUIDs for referencing certain fields
  - New fields for production volumes
