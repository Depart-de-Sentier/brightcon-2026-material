# Brightcon - Brightway beginner course
## Aalborg 2026

# Learning objectives

**Knowledge**
At the end of the course you will know about:
python data structures, python scientific environment, Brightway2 data structures, Brightway2 functions, key concepts of statistical analysis for LCA (error propagation, statistical testing, variance-based sensitivity indicators).

**Skills**
At the end of the course you will be able to: program in python at a basic level, use Brightway2 at a level comparable to other commercial LCA software, including importing foreground and background data into Brightway2, running  calculations from a simple LCA to more complex simulations and comparative analyses, perform statistical analysis of LCA results, perform local and global sensitivity analysis of LCA results.

**Competences**
At the end of the course you will be in a position to: apply LCA modelling in Brightway2 to your research questions, by choosing the appropriate data, code, and workflow organisation, including AI-supported workflow, that solve the case-specific challenges.


# Required setup

What we need for the course is: 

- A text editor, preferably _Visual Studio Code_ (VSC).
- _Python_ (the version is defined during brightway installation, if in doubt use python 3.10)
- Some scientific python packages like _scipy_ and _numpy_ 
- Optionally, _Jupyter lab_ which is a scientific python working environment
- _Brightway_, python-based software for LCA. You need the 2.5 version (also called _Brightway2.5_ release) 
- course notebooks, that are in a Github repository here: [https://github.com/massimopizzol/advanced-lca-notebooks/tree/main/Course-material-bw25](https://github.com/massimopizzol/advanced-lca-notebooks/tree/main/Course-material-bw25)
- A genrative AI software, depending on what your organisation has license for.
