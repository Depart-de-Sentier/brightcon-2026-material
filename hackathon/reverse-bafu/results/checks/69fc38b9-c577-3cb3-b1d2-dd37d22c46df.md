Molar masses from the IUPAC 2021 standard atomic weights: H 1.008, C 12.011, N 14.007, O 15.999, S 32.06, Cl 35.45, Na 22.990. This is the one reaction in the whole set with no co-product and no yield ambiguity: it is a 1:1 addition and the masses close exactly, so the amounts are fixed. Both reagents are themselves unflagged eco-profiles in this same set - and both are rebuilt here from the Althaus report (acetone from the cumene figure, hydrogen cyanide from Tab. 43.2/43.3/43.4) - so this is the deepest chain in the set.
